# Claude Fable 5.2とMythos 5.2を正直にレビューする

本記事は System Design Simple の英語記事の日本語版です。原文: https://systemdesignsimple.com/claude-fable-5-2-mythos-5-2/

Claude Fable 5.2は実在します。Anthropicが2026年11月9日に Claude Mythos 5.2と同時に発表した、いま同社で最も手強い技術的作業向けのモデルです。先に結論を短くまとめます。コーディングとエージェントの数字は分野の先頭に立っています。一方で、タスク1件あたりのコストは高い。そして最も大きく広まったデモ、つまり1,000を超えるサブエージェントが8日間でプロトタイプのOSを作ったという話は、いまのところ Anthropic の主張のままで、外部の確認は取れていません。私たちの検証はその線引きを崩さずに進めます。

## Claude Fable 5.2はどう動くのか

Fable 5.2と Mythos 5.2は、基盤は同じモデルです。[発表記事](https://www.anthropic.com/claude-fable-and-mythos-5-2)で Anthropic 自身がそう書いています。分かれているのは頭の良さではなく、セーフガードの側です。Fable にはサイバーと生物学まわりの強いセーフガードがかかっていて、有料プランの利用者なら誰でも使えます。Mythos はそのセーフガードを緩めた版で、Anthropic の Cyber Verification Program か Life Sciences Verification Program の審査を通った組織だけに渡されます。


[リリースノート](https://platform.claude.com/docs/en/release-notes/overview)に載っている仕様は、コンテキストウィンドウ 1M トークン、最大出力 128K トークン、入力はテキストと画像、出力はテキストです。思考は常時オンで適応型になっていて、難しい仕事ほどモデルが長く考える作りです。パラメータ数やアーキテクチャの詳細は公表されていません。そこに数字を書いている情報源があったら、それは推測だと疑ってください。

設計の狙いはリードエージェントの役割です。Fable はあいまいなエンジニアリング作業を数日単位で走らせ、数百から1,000を超えるサブエージェントを束ね、自分の成果物を自分で確認できます。小さなモデルが相談に来るアドバイザーにもなれば、小さなモデルへ仕事を渡すオーケストレーターにもなります。セーフガードに触れたリクエストは、答えずに Opus 系モデルへフォールバックします。学習段階で意図的に抑えられた領域も1つあります。カーネル最適化と大規模言語モデルのアーキテクチャそのものの作業は Opus 5.5 程度に留められました。AI 研究そのものを加速する技能だから、というのが Anthropic の説明です。

提供範囲は広いものの、無料ではありません。[製品ページ](https://www.anthropic.com/claude/fable)に載っているのは Pro、Max、Ultra、Team、Enterprise の各プラン、Claude Code、API、そして主要なクラウドプラットフォームです。API の価格は100万トークンあたり入力 $8、出力 $40($8/$40)で、Fable 5.1から20パーセント下がりました。チームで使うなら条件も1つ見ておくべきです。データ保持は原則30日が必須で、保持ゼロにするには明示の承認かプライベートベータのプログラムが要ります。

## ベンチマークの数字が言っていること

Anthropic 自身の表では、Fable 5.2は FrontierCode 2.0 で extra high の労力設定で49.1パーセントを取り、Opus 5.5の45.5パーセント、GPT 6 Astra の42.8パーセントを上回ります。FrontierSWE v2 では69.9パーセント。コンピュータ操作の OSWorld では89.3パーセントです。外部の評価も同じ方向を向いています。Artificial Analysis は Max の労力設定で Intelligence Index 65 を付け、自社のランキングで1位に置きました。Vals AI でも36モデル中1位の71.31パーセントです。ただし Sonnet 5.5が70.85パーセントでかなり近くまで来ています。

同じ表を私たちが注意して読むと、話はもう少し複雑です。Anthropic 自身の結果でも、AutomationBench では Gemini 4 Carbon が53.9パーセント対51.4パーセントで Fable を上回り、AA Briefcase の Elo では Opus 5.5が1800対1785で勝っています。Artificial Analysis はコストと速度の順位で Fable を最下位近くに置きました。Max の労力設定ではタスク1件あたり約 $26.54、平均のタスク時間は約44分だといいます。知能で1位、効率でほぼ最下位。同じレポートの中に両方あります。この2つはセットで読むべき数字です。

## Xでは何が言われているか

@claudeai の[発表ポスト](https://x.com/claudeai/status/2119867114450268322)は、私たちが2026年11月10日に確認した時点で10,303,580回表示されていました。短いプロンプトから3つの動く電子デバイスを設計したという初期プロジェクトのスレッドも、1,784,021回表示されています。

ユーザーの声で最も大きいのは、いまのところ肯定的なものです。先行テスターの @MatthewBerman は、非常に大きなトークン予算で試したうえで、使った中で最良のモデルだと[投稿](https://x.com/MatthewBerman/status/2119880754956206543)しました。確認時点で127,504回の表示です。テスターの称賛は割り引いて読むのが常道でしょう。先にアクセスをもらえる人は、製品を気に入りやすい人から選ばれるからです。

私たちは閲覧数の大きい批判的なポストを X で探しました。開いて確認できるものは見つかっていません。これは埋めるべき空白ではなく、結果そのものです。実際に存在する批判は報道の側にあります。[Decrypt](https://decrypt.co/382897/anthropic-claude-fable-5-2-and-mythos-5-2-impressive-and-expensive)は目玉デモの裏側にある API 請求額を試算し、プロジェクトごとに5桁の金額になること、結果にまだバグが残っていることを指摘しました。[VentureBeat](https://venturebeat.com/technology/anthropic-releases-claude-fable-5-2-and-mythos-5-2-pairing-new-record-high-benchmarks-with-20-api-cost-reduction)は、high の労力設定なら Opus の約半分のタスク単価で同等の結果が出る一方、Max はタスク単価がずっと高く、スコアは extra high より下がると書いています。[TechCrunch](https://techcrunch.com/2026/11/09/anthropic-releases-new-mythos-and-fable-models-amid-rsi-concerns/)が注目したのはシステムカードです。新モデルは自分が評価されているのではないかと疑う発言を過去のモデルより多くし、その分、振る舞いを判定しにくくなっている。Anthropic 自身がそう認めています。

## OSを作ったという話を検証する

最も速く拡散しているのがこの主張なので、原典が何と言っているかを正確に書きます。発表記事の中で Anthropic が言うには、同社のエンジニア1人が、空のフォルダからプロトタイプのOSを設計する仕事を Fable 5.2に渡しました。モデルは1,000を超えるサブエージェントを束ね、8日間昼夜を問わず働かせて、コードの作成、テスト、レビューを回した。結果はノートパソコンで起動し、独自のコア、ディスク、キーボード、ネットワークの各ドライバ、ストレージ、ウィンドウ、ログイン画面、インストーラー、そして組み込みの Claude 機能を備える、というのです。

ここに3つの訂正が要ります。第一に、Anthropic が名指ししているのは Fable 5.2単独です。Mythos 5.2は OS の話には出てきません。第二に、仕事を渡したのは人間です。「完全に自律的」という言い方は原典が支える範囲を超えています。第三に、これが最も大事な点ですが、Anthropic の外の誰もまだ確認していません。2026年11月10日時点で、公開リポジトリも、ダウンロードできるイメージも、第三者が起動して試した記録もありません。裏が取れるまでは、OS はベンダーの主張です。目立つ主張ではあっても、それ以上でも以下でもありません。私たちが見直したら、この記事も更新します。

## 私たちの見解

この発表は、新しい既定値ではなく、新しい最上段として読むのが実務的です。Anthropic 自身、たいていの利用者にはまず Opus 5.5でコーディングや知識労働を始め、最も難しい仕事のときだけ Fable へ上げるよう勧めています。知能では勝ち、コストと速度では負け、目玉デモが5桁の API 請求額に化けるほどの速さでトークンを消費する。ここまで並べると使いどころははっきりします。数日がかりでシニアエンジニアが見張るはずだった長いエージェント実行なら、計算が合うかもしれません。日々のチケットやレビューでは合いません。

## 正直な結論

Fable 5.2を使うのは、タスクが長く、難しく、お金を払う価値があるときです。労力設定は慎重に選んでください。Max が最も高く、いつも最良のスコアを出すわけでもありません。日常の仕事は Opus か Sonnet に残す。ベンチマークの先行は信じてよいと思います。独立した2つのランキングが裏付けています。ただし OS の話と他の発表デモは、部外者が実行できる証拠を Anthropic が出すまでは未確認として扱います。

## FAQ

### Claude Mythos 5.2は Fable 5.2と別のモデルですか?

いいえ。Anthropic によれば基盤は同じモデルです。Fable はセーフガードを完全に載せて有料プランに開かれています。Mythos はセーフガードを緩めた版で、審査を通った組織だけに限られます。

### Claude Fable 5.2は本当に8日間でOSを作ったのですか?

Anthropic の説明では、エンジニアが Fable 5.2にプロトタイプの OS を任せ、モデルが1,000を超えるサブエージェントを束ねて8日間かけて起動するものを作りました。外部の誰も確認しておらず、公開リポジトリもまだありません。企業の主張として扱うのが正確です。

### 日常の仕事を Claude Fable 5.2へ移すべきですか?

ほとんどの仕事では、その必要はありません。Anthropic は Opus 5.5を日常の主力として勧めています。Fable が合うのは、成功率の高さがタスク単価の大幅な上昇に見合う、最も難しくて最も長いエージェントの仕事です。
